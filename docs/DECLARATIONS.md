# MedTrace 模型、资源与数据声明（测试版）

- **模型及版本：** 正式模式仅调用主办方.env指定的MODEL_NAME和ENDPOINT，不携带模型权重。当前尚无指定服务实测记录；模型实际版本需由主办方确认。默认temperature=0、seed=42；参数随源码固定并写入运行日志。
- **检索资源：** 默认无外部知识库。随包提示词和确定性校验规则属于项目代码，以提交清单中的哈希为准。可选知识库必须先通过来源、许可和审核校验，再连同其版本清单打包；未经审核的教材索引和知识草稿不随包分发。
- **LLM使用：** 本项目开发和文档修订使用AI编程辅助；运行期使用指定模型生成草稿，由程序执行解析与规则校验。未由医生审核的生成结果不作为临床结论。历史开发曾在公开CMB-Clin等数据上使用非指定模型，相关结果不作为官方评测结果。
- **数据使用承诺草案：** 赛方练习及正式病例只用于授权范围内的比赛和评测，不发送到第三方模型、在线检索或嵌入服务，不对外分发，不缓存测试答案，不逐例人工改写正式结果。提交包默认不含开发数据、真实.env或开发日志。
- **材料真实性：** 模拟测试输出必须标明来源，不替代正式比赛结果；保留真实运行日志，不挑选服务重试中的最佳结果，不伪造临床审核或许可。

以上技术声明对应当前实现。队伍编号尚未分配，当前打包仅为测试；正式承诺须由实际参赛队伍核对并按主办方要求签署，本文不替代团队签署文件。
