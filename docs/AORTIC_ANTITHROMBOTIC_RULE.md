## 1. 任务与边界

阅读当前仓库、竞争赛事 QA、输入输出 schema、既有安全校验和测试后，实施本规范。先核实实际代码与报告是否一致；本文中的行号、函数名及 P05 行为来自任务提供者，未独立读取仓库。保留现有外部接口及正式提交格式，除非确需修改并有相应迁移测试。

目标：避免当前急性主动脉综合征（AAS）病例出现无依据的抗血小板、抗凝及全身溶栓建议；避免误删稳定期患者具有独立适应证的抗栓治疗；确保真实病历事实完整、风险提示进入正式可见输出、复合句完整且可审计。

禁止针对 P05 ID 或其特定措辞硬编码。禁止使用外部在线推理服务作为规则运行依赖。禁止为通过竞赛评分而删除真实病历事实、伪造临床结论或隐藏尚未解决的安全冲突。竞赛有害建议计分规则以仓库内正式赛事文件为准。

本规范定义的是生成文本的安全校验策略，不是临床处方系统。所有人工复核均表示需要临床决策；不得将自动复核提示解释为实际停药、启动用药或批准治疗。临床部署须经过心内科、心血管外科及相关专科审核。

## 2. 临床裁定（实现必须遵守）

| 问题 | 裁定 | 对应实现 |

证据边界：急性 AAS 本身不构成常规抗栓适应证。除特定情境（如 ACS 中疑似主动脉夹层与全身溶栓）外，不应将所有抗凝和抗血小板治疗标为指南规定的绝对禁忌。以下风险分级及输出改写属于工程安全策略，不是指南推荐等级。

## 3. P0：建立疾病状态识别

### 3.1 疾病实体

至少覆盖：

- 主动脉夹层、主动脉剥离、aortic dissection；
- 主动脉壁内血肿、主动脉壁间血肿、主动脉壁间血肿形成、aortic intramural hematoma/haematoma、IMH；
- 穿透性主动脉粥样硬化性溃疡、主动脉穿透性溃疡、penetrating aortic ulcer、PAU；
- 急性主动脉综合征、acute aortic syndrome、AAS。

英文缩写必须有词边界和主动脉上下文，避免 AD 等多义缩写误触发。孤立的慢性 PAU 不自动归为活动性 AAS；主动脉附壁血栓、主动脉壁血栓、非主动脉部位血肿、单纯主动脉瘤不得被误认为 AAS。

### 3.2 状态模型

建议将单一布尔值拆为多个正交属性，具体名称可按现有代码风格调整：

```python
# Illustrative interface; adapt to the repository schema.
@dataclass
class AorticFinding:
    entity: str
    assertion: str  # CONFIRMED | SUSPECTED | RULED_OUT | NEGATED | UNKNOWN
    temporality: str  # CURRENT | HISTORY | UNKNOWN
    activity: str  # ACTIVE | STABLE | UNKNOWN
    repair_status: str  # UNREPAIRED | PERIOPERATIVE | POST_REPAIR | UNKNOWN
    phase: str  # HYPERACUTE | ACUTE | SUBACUTE | CHRONIC | UNKNOWN
    subject: str  # PATIENT | FAMILY | OTHER | UNKNOWN
    evidence: list[str]  # exact source spans / references
```

派生决策状态：`CONFIRMED_ACTIVE`、`SUSPECTED_ACTIVE`、`STABLE_CHRONIC`、`STABLE_POST_REPAIR`、`PERIOPERATIVE`、`RULED_OUT`、`HISTORY_ONLY`、`UNKNOWN`、`ABSENT`。

- 分期参考：超急性 <24 h、急性 1–14 d、亚急性 15–90 d、慢性 >90 d；分期用于辅助判定，不得仅凭时间推断稳定。
- 当前活动性/进展性病变优先于既往病史。已修复的旧病变不否定新的病变。
- 明确当前 CTA 排除结果可解决同一诊断事件的较早怀疑；但旧阴性检查不排除其后新发病变。无法确定时序或存在相互冲突的证据时归为 `UNKNOWN` 并复核。
- `需排除`、`待排`、`不能排除`、`考虑…可能`、`疑似`、`rule out`、`cannot exclude` 表示尚未解决的怀疑；`已排除`、`CTA未见`、`no evidence of` 在作用范围明确时表示排除或阴性。
- `既往`、`术后5年`、`家族史`、`否认既往病史` 分别识别，不得以全文全局关键词或全局否定词消除当前阳性结果。
- 诊断分型、活动性、术后止血情况及独立适应证均必须有输入证据；不允许从模型生成的计划反向确认输入事实。

### 3.3 实现约束

优先利用既有结构化字段（现病史、既往史、影像、诊断、治疗经过及原始医嘱），在实体级识别语义范围。若只有文本，采用局部作用域、时序及分段规则，并保留原文证据；不要求一次性开发通用医学 NLP 模型。无法可靠解析时保守进入复核，不得静默放行或无差别删除整份计划。

不得仅凭模型生成文本中的“已服用”“医生已决定”等措辞把未经来源证实的内容标为真实事实。来源不明时保留可核实信息并提示复核，交由既有事实性校验处理虚构记录。

## 5. P0：决策矩阵与输出策略

### 5.1 决策类型

- `PASS`：保留内容，继续运行其他适应证、剂量及事实性检查。
- `BLOCK`：禁止模型生成的可执行给药建议进入正式诊疗计划。保留来源事实，生成医生可见风险提示。用于明确禁忌或无依据的高风险推荐。
- `REVIEW`：将有争议、条件不足或存在竞争适应证的给药建议从可执行计划中移除，替换为明确的评估事项。原候选文本仅保存在审计记录或标明“未授权/待确认”的复核字段，不得以正向医嘱形式再次进入正式输出。
- `REVIEW_URGENT`：同 `REVIEW`，额外指出竞争风险、临床紧迫性及所需专科评估。不得通过自动停药或继续用药来解决冲突。

以上动作针对生成的计划。真实来源医嘱及用药史不得篡改；若存在临床冲突，保留原始记录并提示医生核对。对真实医嘱的停药、逆转、改剂量或恢复只能由医生决定。

### 5.2 基础矩阵（生成的新用药建议）

| 类别 | 确诊活动性 AAS | 当前疑似 AAS | 稳定慢性/稳定修复术后 | 围术期 | 仅既往史/已排除/无病变 | 状态不明 |
|---|---|---|---|---|---|---|
| 常规全身溶栓 | BLOCK | BLOCK | REVIEW | REVIEW | PASS* | REVIEW |
| 治疗性抗凝 | REVIEW 或 BLOCK** | REVIEW 或 BLOCK** | PASS* | REVIEW | PASS* | REVIEW |
| 单药/双联抗血小板 | REVIEW 或 BLOCK** | REVIEW 或 BLOCK** | PASS* | REVIEW | PASS* | REVIEW |
| 预防性抗凝 | REVIEW | REVIEW | PASS* | REVIEW | PASS* | REVIEW |
| 操作相关抗凝 | REVIEW | REVIEW | PASS* | REVIEW | PASS* | REVIEW |
| 局部操作、监测、真实历史、风险评估 | PASS* | PASS* | PASS* | PASS* | PASS* | PASS* |

`*` 仅表示不因该条规则拦截，其他校验仍生效。仅有既往史但伴当前病情不明时使用 `UNKNOWN`，不直接按稳定期放行。稳定期及围术期溶栓须依据相应适应证和一般禁忌证复核，本规则不建立普遍禁忌。

`**` 确诊或疑似当前 AAS 时，无输入支持的独立适应证却提出常规抗凝或抗血小板，标记 `BLOCK`；有已记录或可能存在的竞争适应证，标记 `REVIEW` 或 `REVIEW_URGENT`。疑似夹层的常规全身溶栓硬拦截依据为 ACS 指南；其他溶栓场景应适用相应专科禁忌，本软件保守拦截未经确认的全身溶栓提案，不将其泛化为所有局部纤溶操作的指南绝对禁忌。

### 5.3 独立抗栓适应证

识别与具体药物类别相关的输入证据，包括机械人工瓣膜、具有抗凝指征的房颤、急性 DVT/PE、心腔内血栓、近期 PCI/冠脉支架、明确独立冠脉血栓性 ACS、体外循环及其他明确介入操作。

- 仅出现“房颤”不等于已确认抗凝适应证，也不能据此生成或改用 DOAC。机械瓣需符合相应抗凝规范。
- 仅出现“ACS”或肌钙蛋白升高不能证明独立冠脉血栓事件。AAS 累及冠脉开口可导致冠脉灌注不良，应提示主动脉及冠脉病变的紧急联合评估。
- 近期支架、机械瓣、急性 PE 等明确竞争风险时，对活动性 AAS 的抗栓冲突应使用 `REVIEW_URGENT`；不要自动放行，也不要生成确定性停药或继续用药医嘱。
- 若真实来源中已有专科制定的个体化围术期抗凝方案，应保留事实；模型不得独立改变该方案。

### 5.4 预防性抗凝

不以“肝素”词条或剂量数值单独判断预防与治疗用途。应结合药物、剂量、频率、明确指征、手术和出血信息；意图不明时使用 `ANTICOAGULATION_UNSPECIFIED`。

对尚未修复、出血风险不明或存在活动性 AAS 的患者，建议输出：

> 评估 VTE 风险与出血风险；在无相关禁忌时考虑机械性预防，药物性预防的适应证和启动时机由经治医师结合主动脉病变及止血情况确定。

术后止血稳定且无显著出血风险的患者可以存在药物性预防指征。心脏外科术后早期药物预防指南的时间窗口不应直接外推到未修复 AAS，也不能根据本条规则自动生成给药时间。

## 8. P1：独立药物剂量校验

P05 同时暴露负荷剂量与维持剂量混淆。与 AAS 规则分离实现或复用既有通用剂量校验：

- 对照来源中的一次性负荷量与生成计划中的重复每日用药；识别 mg/d、mg/日、qd、每日、daily 等频率。
- 常规 ACS 维持剂量示例：阿司匹林通常 75–100 mg/d，氯吡格雷通常 75 mg/d。负荷方案及特殊方案依具体适应证和指南判定，不建立跨疾病全局固定剂量限制。
- 阿司匹林300 mg/d、氯吡格雷300 mg/d 作为常规 ACS 维持方案应触发高风险剂量复核，即使无 AAS。
- 不擅自把300 mg改为75 mg；对于当前 AAS，优先处理适应证冲突；剂量规则应记录独立发现。
- P0 必须覆盖 P05 中该风险组合；通用剂量引擎的全面实现可作为独立 P1 PR，但不能在交付报告中声称未实现的覆盖率。

## 9. 正式输出与审计

复核提示必须进入官方可见的输出字段（以当前竞赛 schema 为准），不得只在内部日志报告。建议格式：

## 11. Agent 执行顺序

1. **Repository audit（P0）**：定位现有调用链、F5、可见复核字段、P05 fixture、测试框架；运行现有测试，记录基线及失败项。核对赛事规则和部署限制。
2. **Clinical state extraction（P0）**：实现病变、时相、确定性、主体、活动性和证据作用域识别；先提交对应单元测试。
3. **Decision policy（P0）**：实现用药意图及来源识别、独立适应证、分级矩阵；将判断与文本改写分离，确保可单独测试。
4. **Safe rendering（P0）**：修复复合句、保留真实事实和不相关安全内容，集成医生可见提示与审计；确保正式序列化后仍满足规则。
5. **Dictionary and dose validation（P1）**：扩展中英药物词典，建立独立剂量复核或复用已有模块；添加专门回归测试。
6. **Integration and delivery**：执行全量测试及 P05 回归；如有现有模型评估脚本，比较修复前后输出及误拦截，不强制调用外部服务。记录所用命令、真实通过/失败数、未执行项目和原因。
7. **Documentation**：更新现有架构/规则文档及 changelog，登记临床来源、词典版本和未解决限制。保留临床审核状态为 pending，不声称获得医生批准。

若多个 Agent 并行执行，建议分别负责状态提取与词典、策略与安全输出、测试与集成，由负责人统一接口和验收。禁止多个 Agent 无协调地修改同一函数；以小型可审查提交为单位进行合并。

| §9 正式输出与审计 | `review_messages()` 生成官方可见复核项（severity=high，不引用草稿原文）；`Event` 审计事件写入 run log `aortic_rule_events`；`aortic_postcheck_changes` 校验定稿计划 |
| 集成 | `medtrace/pipeline.py`：主动脉校验为最后一个计划改写步骤；`medtrace/verify.py`：`aortic_antithrombotic` 高危发现、F5 出血风险去重、保留 `recorded_aortic` / `remove_aortic_antithrombotics` 旧接口 |
| §10 回归测试 | `tests/test_aortic_rule.py`：A01–A36 及 P05 固定回归（含端到端官方输出） |

### 矩阵落地细节（规范留给实现决定的部分）

- 确诊或疑似活动期：无独立适应证的常规抗凝/抗血小板 → BLOCK；有紧急竞争适应证（机械瓣、急性PE、DVT、心腔内血栓、冠脉支架）→ REVIEW_URGENT；仅有房颤 → REVIEW（"房颤"本身不等于已确认的抗凝适应证）。
- 模型生成的停药、暂停措辞：患者确有该类用药时 → REVIEW，写"评估暂停…的必要性及时机"；病历从未显示给过该类药时（"暂禁用/避免抗凝"），没有可停的治疗，属安全提示 → PASS，原样保留（2026-11-24 应用户要求修订 A22）。"暂停或谨慎使用"并列选项仍 → REVIEW。
- 条件性给药（"若…可考虑恢复"）→ REVIEW，整句改写；只把决定留给会诊、本身不含给药动作的句子 → PASS。
- 围术期、状态不明 → 给药建议一律 REVIEW；稳定慢性/稳定修复术后 → PASS（溶栓 REVIEW）；仅有病史而未记录病变稳定 → UNKNOWN，不按稳定期放行。
- F3（"已"改"拟"）不再改写病历证实的经过：病历显示给过的抗栓药类别，以及病历中以完成语态记载的同一处置（"已行冠脉造影"）。P05 云端运行中，"鉴于已使用抗血小板药物"曾被改成"鉴于拟使用…"。
- 时间推算：从时长（"突发胸痛5小时""术后第3天""1年4个月前"）或日期对资料截止时间（无截止时间时用病历中最晚日期）计算天数，分为超急性 <24 h、急性 1–14 d、亚急性 15–90 d、慢性 >90 d；同一句取最近的变化（"胸痛5年，加重1周" 取 1 周）；日期、年龄、月经周期、"3天后/48小时内"这类间隔不计。本次确诊病变按时间超过 90 天且无"急性/新发/进展"措辞 → UNKNOWN（复核），既不按急性拦截也不按稳定放行。
- 竞争适应证时间窗（工程取值，待临床确认）：冠脉支架 12 个月（`RECENT_STENT_DAYS`），急性肺栓塞/深静脉血栓 90 天（`ACUTE_VTE_DAYS`）；窗口内或时间不明 → REVIEW_URGENT，窗口外 → REVIEW。只认冠脉支架（主动脉、颈动脉、胆道等支架不计）；"机械瓣"为紧急适应证，类型未明的人工瓣膜/换瓣 → REVIEW。
- UNKNOWN 还覆盖：本次资料对同一病变既有确诊又有否定（"CTA示主动脉夹层"/"CTA未见主动脉夹层"）；同一分句同时含既往与本次措辞。"未见血肿进展"否定的是进展而非病变。

### 已知限制

1. 状态和意图识别基于局部文本规则，输入是自由文本，没有结构化字段可用；改写过的真实医嘱（非逐字抄录）会被当作模型生成。
2. 时间推算基于病历中的时长和日期文字；"第8天突发肺栓塞"这类相对于另一事件的时间按距今处理；时间不明的支架、肺栓塞按窗口内（保守）处理。
3. 剂量引擎覆盖 11 种有固定成人剂量的抗栓药；华法林（按 INR 调整）、依诺肝素等低分子肝素（按体重）、普通肝素无固定上限，不做剂量判断；阈值为说明书成人值，不考虑肾功能、体重、年龄调整。
4. 真实语料中主动脉综合征病例很少（1,353 例中 6 例），验证覆盖有限；合成测试和真实语料通过不代表敏感度、特异度或真实世界安全性。

### 待临床审核（发布门槛，见 §14）

疑似 AAS 的风险分层阈值；各类抗栓在围术期与竞争适应证下的处理；VTE 预防措辞；"暂禁用/避免"措辞在未用药时保留（A22 修订）；房颤是否升级为紧急复核；冠脉支架 12 个月、急性 VTE 90 天时间窗及"时间不明按窗口内"的保守处理；本次病变超过 90 天且无急性措辞转复核的规则；剂量引擎阈值（`medtrace/dosing.py` 的 `DOSE_RULES`）；医生可见复核措辞；与医院用药审批制度的兼容性。审核时请记录审核者、日期、版本、变更内容和证据来源。
