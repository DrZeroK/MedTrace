# 安全要点阈值与出处核对

范围：`medtrace/safety_points.py` 的七条触发规则，以及 v3 提示词中严重程度分级所举的标准。核对日期 2026-11-24。

**核对方式。** 国际指南通过网络检索核对（多为指南摘要、官方页面或权威二手总结，未逐页阅读全文）；中文依据优先使用本仓库已登记的人卫第10版教材文本（`data/reference_indexes/textbooks-text-21-v2/`，下表“书页”为原书页码标签），中国指南全文均未取得，单独列出待补。“状态”一栏：

- **已核实**：检索到指南原文、官方页面或直接引文，或在教材中找到对应原文，数值一致。
- **二手来源**：数值来自可信二手总结，指南原文未取得。
- **启发式**：触发条件是本项目为筛查设定的工程阈值，不是指南定义；它只决定是否提示模型，不进入病历正文。
- **冲突**：中外依据数值不一致，处理方式见备注。

本文件不构成临床建议，规则须经临床专家审阅。

- 中国指南原文：《中国急性缺血性卒中诊治指南2023》《中国卒中学会急性缺血性卒中再灌注治疗指南2024》（溶栓时间窗、血压阈值、取栓窗）、《输卵管妊娠诊治的中国专家共识》（2019）、《妊娠剧吐的诊断及临床处理专家共识（2015）》、《中国2型糖尿病防治指南（2020年版）》低血糖章节、中国脓毒症急诊指南。需通过中华医学会期刊或机构数据库获取。
- 2026 AHA/ASA 指南全文（溶栓前后血压阈值的现行条文）。

## 四、本轮改动

1. 卒中：主依据改为 AHA/ASA 2026；补充替奈普酶、延长时间窗溶栓须高级影像、基底动脉闭塞 24 小时内取栓；185/110 注明来自 2019 版。
2. 低钾：因教材与 NHS 速度不一致，提示词删去具体速度，改写“外周含钾 ≤40 mmol/L、按医院规程控制速度、快速补钾须心电监护、见尿补钾”。
3. 其余规则补充中文教材出处；冲突与未取得原文的条目逐项标注。
