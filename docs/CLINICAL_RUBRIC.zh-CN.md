# 临床错误分类与评分标准（待临床负责人签署的草案）

[English](CLINICAL_RUBRIC.md) | **简体中文**

## 严重程度

- **危急（严重）** —— 若按该病程记录行事，可能切实导致患者受到伤害；或在影响诊疗决策的问题
  上歪曲了记录。只要出现一处危急错误，该病例即计入危急错误率。
- **重要** —— 具有临床相关性的不准确或遗漏，但不太可能直接造成伤害。
- **轻微** —— 措辞、顺序、冗余问题；无临床后果。

## 错误类别

| 代码 | 类别 | 何时判定为危急… |
|---|---|---|
| F1 | 编造发现、病史、结果或治疗 | 影响诊断或治疗时 |
| F2 | 数值、单位、侧别、剂量或时间错误 | 错误数值跨越决策阈值或改变剂量时 |
| F3 | 否定错误（阴性写成阳性，或反之） | 该发现为警示信号或禁忌时 |
| F4 | 未记录项目被写成正常 / 阴性 / 不存在 | 涉及过敏、抗凝、妊娠、待回报结果或警示信号时 |
| F5 | 时序错误（顺序颠倒、系列数值合并、截止点后信息） | 趋势或时机驱动诊疗（如时间窗）时 |
| F6 | 拟行干预写成已完成，或已完成写成拟行 | 可能导致某项治疗的遗漏或重复时 |
| F7 | 遗漏关键事实 | 所遗漏事实为禁忌、警示信号或时间敏感性发现时 |
| F8 | 记录冲突被静默化解 | 冲突涉及过敏、用药或诊断时 |
| R1 | 诊断确定性高于证据支持程度 | 若换成替代诊断，诊疗将不同时 |
| R2 | 遗漏重要鉴别诊断 | 被遗漏的替代诊断危及生命且未被排除时 |
| R3 | 泛化 / 无关的鉴别诊断清单 | —（至多为重要） |
| R4 | 未承认不确定性或信息缺失 | 某项决策依赖于此 |
| P1 | 计划与已记录的过敏、用药、器官功能、妊娠、抗凝相冲突 | 一律 |
| P2 | 遗漏时间关键性措施 | 一律 |
| P3 | 计划项与任何已记录问题无关 / 已记录问题无对应计划 | 未处理的问题紧急时 |
| P4 | 不安全的特定建议（剂量、给药途径、禁忌操作） | 一律 |
| E1 | 证据引用不能支持其陈述 | —（至多为重要） |

## 评分（1–5）

**临床推理** —— 5：所有问题均被识别并排出优先级；评估分级且依据记录加以论证；
鉴别诊断具体并附支持/反对依据；不确定性明确陈述。4：存在轻微缺口。3：主要诊断正确，但推理单薄或
部分泛化。2：遗漏重要问题或鉴别诊断，或确定性判断失当。1：推理不安全或与记录无关。

**诊疗计划** —— 5：每一项均对应已记录的问题、个体化、对照记录安全，并含监测与决策节点；
已完成与拟行的区分清晰。4：存在轻微缺口。3：恰当但泛化。2：遗漏相关项或依据薄弱。
1：不安全或与记录相矛盾。

## 流程

两位审核人，对变体设盲，顺序随机（`python -m eval.blind_review export …`）。审核人依据记录
独立评分，而非对照某一份参考病程记录；`eval/cases.json` 列出可接受的诊断、鉴别诊断与计划
要素，作为指导，而非唯一正确答案。任一位审核人标记为危急，则该病程记录暂定为危急；
关于 `critical_error` 的分歧由临床负责人裁定。
按类别报告计数及病例数，绝不仅报告均值。
