## 2. 可复现的故障机制

| 环节 | 离线验证 | 影响 |
|---|---|---|
| JSON 诊断 | `medtrace.note.parse_json_object` 先解析清理后的全文，再试首个左花括号至最后一个右花括号，最后尝试去尾逗号。以合成输入测试，未转义双引号和对象成员间漏逗号都报 `Expecting ',' delimiter`。截断样本 `{"items":[{"x":1},{"x":2}],"y":"unfinished` 的全文错误为字符串未结束，最终对外错误却为缺逗号 | 报错位置可能指向截取后的候选。单凭行列和消息无法选择修复措施 |
| 清理过程 | 向解析器传入 `{"text":"literal ,] preserved",}`，返回正文 `literal ] preserved` | 去尾逗号的正则在字符串内部也生效。全局替换可能改变原文；本批是否发生这一问题没有证据 |
| 生成重试 | A2 使用原资料和通用格式提醒重写整份。用本地替身连续返回两次畸形 JSON，复现 2 次逻辑调用、2 条解析错误、最终 fallback。`raw_parse_retries` 在异常退出时缺失 | 泛化提醒不能保证语法正确。将缺失计数读为 0 的下游统计会漏记失败病例的重试 |
| 评分及缓存 | 用 `5f5c87a` 的评分入口和本地替身输入两份合成病历。裁判第一次返回破损 JSON，第二份只给 fidelity=9。脚本退出码为 0，第一例未评分，第二例被缓存并记 18/100。单测评分函数时，空 scores 对象还会被算作 0 分 | 进程退出、JSON 可解析、五维评分有效是三个独立状态。已有缓存的无效条目也会影响续跑 |

项目有一例可供对照的历史证据。`cmbclin-001` 使用的是 **Qwen3.5-27B**。重放保留的第 148、150 次响应，两次均以 `finish_reason=stop` 结束，均在 16 行 65 列因中英文引号混用失败。第 151 次纠错后可解析。这支持优先排查引号，但无法据此归因为本批 Qwen3.8 的四例。详见 [历史复盘](FAILURE_FIX_20261118.md)。

## 3. 修复顺序与交付

| 顺序 | 操作 | 验收 |
|---|---|---|
| P0　取回现场 | 从服务器原运行目录提取与 `output_random10_fixed.json` 同级的 `run_log.json`，或从 `logs/run_log.jsonl` 提取对应批次。按模型、绝对时间和病例顺序匹配。取裁判 stderr、运行版本和已有原始回复。核对每次请求实际发送的模型、模板版本、seed、thinking、输出上限、response_format、超时及重试预算 | 每次失败能关联病例、阶段、尝试序号、终止原因、原始错误。丢失的历史原文标作“无法恢复”。后续复现另设运行编号 |
| P0　补评 | 冻结原 10 份输入与输出、原缓存和报告。复制原评分目录，用相同评审配置及原始完整文件重跑，复用四份有效缓存，仅请求两份缺评病历。把标准错误和逐例状态一起保存 | 这 2 例完成五维校验或各自有明确失败原因。其余四例分数及原始病历内容不变。修改裁判模型、提示词或思考配置时使用独立批次，对所有成功病历按新口径评估 |
| P1　可靠诊断 | 先保存完整候选的首个解析异常，分别记录原始与清理后坐标、候选类型、每次请求的 finish_reason、输出字符数和服务端实际回报的 token 数。区分逻辑调用、HTTP 尝试、解析失败和实际发起的重新生成次数。仅开发复现时在受控本地目录留存失败回复；常规日志保留摘要或哈希 | 同一个截断用例可同时看见原始错误和截取候选的次级错误。重试预算为 1 或 2、成功或异常退出时，计数都与实际请求一致 |
| P1　按错误类型恢复 | 在同一服务上用合成探针确认 JSON 对象或 Schema 约束确实生效，检查请求参数被接受且实际输出遵守约束。生成器约束内部草稿字段（含 `treatment_plan`）；序列化后再单独校验正式提交字段（含 `plan`）。合法 JSON 缺段走字段校验；确认长度截断后评估输出预算与可用时限；正常停止且语法错误时才走格式纠正。只在字符串外处理确定性的语法噪声，拒绝猜补含义不明的正文 | 首轮、重试后通过率分别报告。数字、否定、时间、单位、证据编号在确定性清理前后逐值一致。无可用预算时显式失败，不将残缺记录标记成功 |
| P1　评分完整性 | 在写缓存和读缓存时验证五个维度齐全、值为有效范围内的数值，并核验重大错误列表类型。有效评分才入成功缓存。语法错误或字段缺失至多纠正一次，保存失败类型。按生成失败规则零分、五维有效、裁判失败分别计数。评测验收模式存在缺评时返回非零退出码，同时保留已完成结果 | 仅 fidelity=9 或空 scores 必须标为无效评分，不能计为 18 或 0。重复执行只补缺失或无效的评分，规则零分与裁判故障在汇总中可区分 |
| P2　验证与推广 | 四例 fallback 作为已知故障集，先补证据，再把原配置与候选配置逐例配对。六份已有成功病历保留作对照。另用未调参的 CMB-Clin 和 TypicalCase-DC 样本复验，按来源报告指标。人工核对原材料中的关键事实和评分变化 | 固定回归样本全部通过，畸形输入有明确错误，成功样本无正文篡改、无超预算；未见病例另报生成率、可评分率、临床质量、耗时与实际样本分母。已知故障集的通过率不作为总体成功率 |
