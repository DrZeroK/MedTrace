# 比赛要求与验收边界

[English](REQUIREMENTS.md) | **简体中文**

主办方提供的汇总指南附录 3 定义了已实现的运行协议。主办方最新发布的版本优先。此前问答中关于命名的存疑之处，不能覆盖这一基于完整本地指南的实现。

| 要求 | 实现与回归覆盖 |
|---|---|
| Python 3.11、requires.txt、不带参数运行 main.py | CI 与隔离的包入口测试 |
| 仅从 main.py 同目录的 .env 读取 MODEL_NAME 与完整的 ENDPOINT | 官方解析器；受污染的工作目录/环境测试 |
| 无必需的密钥、Authorization、继承的凭据或代理 | 无密钥客户端与传输测试 |
| 固定使用根目录下的 input.json 与 output.json | 官方配置忽略环境变量中的路径覆盖 |
| 数组输入；case ID 为唯一非空字符串 | 任务级校验；退出码 2 |
| 有效的 cutoff、唯一的字符串 source ID、字符串 content | 逐例校验；失败记录保留在原位 |
| 完整的段落、evidence 与 review 字符串 | 严格的模型解析、最终结构检查与病例内引用检查 |
| 面向临床的 review_items | 官方输出不包含引用草稿原文的校验/QA 消息；诊断过度肯定等高价值发现以干净话术保留；模型、台账、截止时间与知识降级提示仍保留 |
| 输出顺序与输入一致；支持失败与空输入 | 批量测试 |
| 整批完成后原子发布 | 官方模式从不发布中间结果；中断测试 |
| 官方运行安全上限 | 无参数入口默认每例 300 秒、整批 3600 秒（安全值，不是主办方限额）；开发模式仍为不限；到达截止时间时生成符合 schema 的兜底记录，并仍发布完整批次 |
| 本次运行的 run_log.json | 运行 ID、病例/请求时间戳、计数器、token 用量与 I/O 哈希 |
| 固定的提示词/参数版本与随机种子 | 代码默认值、提交清单、run_start 配置 |
| JSON 输出模式 | vLLM 原则上支持 text/json_object/json_schema；具体参数与 Schema 特性待确认。官方路径不发送 response_format；开发模式可发送 json_object；json_schema 尚未实现 |
| Embedding 服务与硬件评分 | 计划提供内网 Embedding API；其 NPU 资源由赛方管理，不计入参赛方硬件评分；调用量统一管理。运行时仍为纯 CPU，不得自部署向量模型；当前设计不使用 Embedding |
| BGE-M3 参考配置 | Dense 1024 维、最长 8192 tokens、中文/多语言、FP16、无需 Instruction，先开放 Dense API。endpoint、认证、配额与最终模型版本待公布 |
| 合法、固定版本、已登记并随包分发的离线资源 | 默认不使用外部知识库；经校验的发布版本从包内加载 |
| 源码与结果对应 | SHA-256 清单与结果包检查会拒绝被更改的输出、过期日志与被更改的资源 |

开发配置需要 --development（或在评测模块中传入 development=True）。它保留既有实验功能；不会影响官方的无参数入口。

主办方截至 Q16 的答复（2026-11-20）不改变运行时设计：不依赖前缀缓存（评测可能关闭缓存，延迟可能更慢）；算法在纯 CPU 环境运行；运行时不使用 Embedding 服务；未来若做向量检索，必须使用主办方的内网 Embedding API；随包分发的本地知识库或索引必须固定版本、完成登记，并符合公布的大小限制。

2026-11-20 的补充答复确认：vLLM 原则上支持 `text`、`json_object`、`json_schema`（具体参数与 JSON Schema 特性待确认）；Embedding 的 NPU 资源不计入参赛方硬件评分，但调用量统一管理；计划采用 BGE-M3（Dense 1024 维、8192 tokens、FP16、无需 Instruction，先开放 Dense API）。当前运行时仍不发送 `response_format`，也不使用 Embedding；BM25 教材实验仍为纯 CPU、位于提交包之外。

当前打包仅用于测试；队伍编号尚未分配。正式结果需要获授权的病例与真实完成运行的日志。模拟输出不是正式结果。

仍需外部验收：指定的模型/服务版本；最终的请求、病例与任务限额；token/调用/重试/并发预算；response_format/JSON Schema 参数清单与示例；Embedding endpoint、认证、配额与最终 BGE-M3 版本；本地知识库/索引大小限制；包大小与资源登记模板；临床审查；队伍资格与已签署的声明。默认值仅为测试设置。正式提交时，需按主办方模板渲染项目说明，并核实十页上限。
